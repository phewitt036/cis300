# CIS 300 — Web Design

Everything for the course in one place, so it is the same on x8 and the MacBook.

## Layout

| Folder | What it is |
| --- | --- |
| `phewitt2-chNCS/` | Pacific Trails Resort case study, one folder per chapter. The folder name is the graded naming convention (ASURITE + chapter) — do not rename it. |
| `submitted/` | The zips as handed in, one per chapter. |
| `cis300-site/` | Class project: the Bench Notes fantasy advisor landing page — wireframes and the assignment doc. Front end only, no back end or database allowed. |

## Working on either machine

Pull before you start, push when you stop:

```bash
git pull
# ...do the work...
git add -A && git commit -m "ch9: nav bar" && git push
```
